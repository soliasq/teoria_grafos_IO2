# ============================================================
#  REQUERIMIENTOS DEL PROYECTO
#  Red Sanitaria Bolivia - CEASS
#  Sistema web de optimización logística con Teoría de Grafos
# ============================================================
#
#  Este proyecto es 100% FRONTEND (HTML + CSS + JavaScript).
#  NO requiere instalación con pip, npm, ni ningún gestor de
#  paquetes. Todas las dependencias se cargan vía CDN.
#
#  Solo necesitas un navegador moderno y conexión a internet
#  (para las librerías externas y los mapas).
#
# ============================================================
#  1. REQUISITOS DEL SISTEMA
# ============================================================
#
#  SISTEMA OPERATIVO:
#    - Windows 10/11
#    - macOS 10.15+
#    - Linux (Ubuntu 20.04+, Debian, Fedora, etc.)
#
#  NAVEGADOR WEB (uno de los siguientes):
#    - Google Chrome 90 o superior
#    - Mozilla Firefox 88 o superior
#    - Microsoft Edge 90 o superior
#    - Safari 14 o superior
#    - Opera 76 o superior
#
#  CONEXIÓN A INTERNET:
#    - Requerida (para cargar CDNs y tiles de mapas)
#    - Mínimo: 1 Mbps
#    - Recomendado: 5 Mbps
#
#  RESOLUCIÓN DE PANTALLA:
#    - Mínimo: 1280 x 720 px
#    - Recomendado: 1920 x 1080 px
#
#  MEMORIA RAM:
#    - Mínimo: 2 GB
#    - Recomendado: 4 GB
#

#  4. INSTALACIÓN PASO A PASO
# ============================================================
#
#  OPCIÓN A — USO DIRECTO (SIN INSTALAR NADA)
#  -------------------------------------------
#  1. Descarga el proyecto (ZIP o git clone)

#  3. Abre app/index.html en tu navegador
#  4. ¡Listo! No necesitas instalar nada
#
#  OPCIÓN B — SERVIDOR LOCAL CON PYTHON
#  -------------------------------------------
#  1. Instala Python 3.8+
#  2. Abre una terminal en la carpeta del proyecto
#  3. Ejecuta:
#       python -m http.server 8000
#  4. Abre: http://localhost:8000/app/index.html
#
#  OPCIÓN C — LIVE SERVER EN VSCODE
#  -------------------------------------------
#  1. Instala Visual Studio Code
#  2. Instala la extensión "Live Server"
#  3. Abre app/index.html en VSCode
#  4. Click derecho → "Open with Live Server"

# ============================================================
#  6. NOTAS IMPORTANTES
# ============================================================
#
#  🔸 Este proyecto NO usa backend (servidor, base de datos).
#  🔸 Todos los datos se procesan en el navegador.
#  🔸 Los CSV son la única fuente externa de datos.
#  🔸 El mapa requiere conexión a internet (tiles).
#  🔸 Las librerías requieren conexión para cargar la 1ra vez.
#
#  🔸 Si no hay internet:
#      - El mapa NO cargará los tiles
#      - Las librerías NO cargarán
#      - El sistema mostrará errores
#      - Solución: Conectar a internet
